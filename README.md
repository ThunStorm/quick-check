# Quick Check

一个尽可能轻量的桌面字典应用，常驻系统菜单栏或任务栏托盘，方便随时快速查词。

- 点击通知区域图标，弹出一个半透明、Liquid Glass 风格的小搜索框。主流程直接输入，可选的自定义唤起快捷键留待后续。
- 默认主语言为简体中文，第二语言为英语，可在语言设置中修改。应用自动识别输入语种，在主语言和当前第二语言间双向翻译。
- 输入框左侧的语言下拉框可临时切换第二语言。闲置 5 分钟后，下一轮查询恢复使用设定的默认第二语言。
- “轻”同时体现在常驻资源占用低、查完即可收起，以及结果信息完整而精炼。收起方式和结果字段待细化。
- 中英和中日词语随输入查询本地词典。按 Enter 可调用配置好的翻译接口，支持多种语言组合。
- 译文要忠实、地道，保留原文的语气和正式程度，优先采用目标语言里自然的搭配。结果先给可直接使用的表达，有影响理解的歧义时再简短说明。
- 翻译完成后可从结果旁的按钮切换语气，基于原文重新生成。建议默认沿用原文语气，可切换为更随和或更正式的表达。

### 后续的英文邮件回复

初版设计时就考虑邮件回复与翻译共用同一弹窗、结果区和重生成操作。建议在用户主动选择「回复邮件」后，展开来信和回复要点的输入位置，允许用中文说明想怎么回，生成可直接使用的英文草稿。调整语气、目标词数等条件后，可沿用来信和要点重新生成。具体入口和控件排布待定。
